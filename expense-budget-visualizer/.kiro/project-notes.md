# Expense & Budget Visualizer — Project Notes

This project follows the CodingCamp mini-project requirements.

## Required stack
- HTML
- CSS
- Vanilla JavaScript
- Browser Local Storage
- Chart.js via CDN
- No backend
- No frontend framework

## Required MVP
- Item Name, Amount, Category inputs
- Food, Transport, Fun categories
- Required-field and positive-amount validation
- Add transactions
- Scrollable transaction list
- Delete transactions
- Automatic total balance
- Automatic pie chart by category
- Local Storage persistence
- Responsive mobile-friendly design

## Optional challenges implemented
1. Monthly summary
2. Sort transactions
3. Dark/light mode

## Folder rules
- One CSS file: css/style.css
- One JavaScript file: js/script.js
- Main HTML: index.html
- Keep .kiro folder in the repository for submission.

## GitHub Pages
The app is static and can be deployed directly with GitHub Pages.
